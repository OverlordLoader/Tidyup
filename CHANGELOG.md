# Tidy Up! — Changelog

Running reminder of what changed / was added (Henry's standing rule so other AI tools can see it).

## 2026-09-29 — Milestone 1: playable core

**New repo:** `OverlordLoader/tidyup` (public), bundle ID `app.tidyup.game`, display name "Tidy Up!".

**Game (fully playable, 50 levels):**
- Added classic color-sort mechanic: tap tube → tap destination to pour the top color run; pours only onto matching color or empty tube; tube completes at 4-of-a-kind; level wins when all tubes are complete or empty.
- Added seeded level generator (`Game/LevelGenerator.swift`): 50 deterministic levels, difficulty ramp 3 colors/2 spare tubes → 8 colors/1 spare tube. Levels are built by reverse-shuffling single segments from the solved state (segments may land on unlike colors, so deals are genuinely mixed); every level is *certified* — the recorded inverse move sequence is replayed through the real gameplay rules and the deal ships only if every inverse is legal and the board ends solved. Deals with a pre-completed tube or fewer than 2 mixed tubes are rejected.
- Added unlimited undo, restart, move counter, par-based 1–3 star ratings, level select grid with locks/stars, progress persisted in UserDefaults.
- Added title screen with How-to-play sheet and sound toggle. No timers, no fail states.

**Juice (SpriteKit):**
- Added glossy tube rendering: glass body with specular stripe, candy liquids with bright surface ellipse, selection lift + glow.
- Added pour animation: tube tilt + 3 staggered liquid blobs on a curved path + splash particles + pop.
- Added tube-complete celebration (star burst + scale pop + chime arpeggio) and level-win confetti rain + fanfare.
- Added illegal-move shake, ambient background bubbles, gradient background with soft color glows.
- Added runtime-synthesized SFX (`SoundManager.swift`: click, pour glug, pop, complete arpeggio, win fanfare, error) — no audio assets.
- Added haptics on select, pour landing, completion, win, error (`Haptics.swift`).
- All textures procedural (`NodeTextures`); app icon generated via `scripts/generate_icons.py`.

**Project / pipeline:**
- Added Xcode project generated by `scripts/generate_project.py` (project.pbxproj + App.xcscheme, scheme "App", iOS 17+, Swift 5).
- Added `.github/workflows/apple-release.yml` (native-app adaptation: PR safety tests + manual signed release via `app-store-release` env).
- Added `scripts/apple-release.py` / `apple-release-test.py` adapted from sibling apps; `ALLOWED` gains `app.tidyup.game`.
- Added `Info.plist` (portrait iPhone, "Tidy Up!" display name) and `PrivacyInfo.xcprivacy` (zero data collection).
